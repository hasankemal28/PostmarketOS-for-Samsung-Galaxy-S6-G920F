Installation using TWRP adb sideload
This is the recommended method for Samsung devices to avoid partitioning issues:

Download the latest .zip from the Releases page and latest TWRP

Boot your device into TWRP Recovery.

Connect the phone to your PC via USB.

In TWRP: Go to Advanced -> ADB Sideload -> Swipe to Start.

On your PC, run:

adb sideload your_filename.zip
In TWRP click Reboot -> System
